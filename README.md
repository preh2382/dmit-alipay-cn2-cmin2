## 支付宝付款的实际操作流程

进入 DMIT 官网下单页面后，选好套餐，进入结账环节，付款方式列表里会出现 Alipay 选项。点选之后会跳转到支付宝的标准收银台页面，用手机 App 扫码或者网页端登录都可以完成支付。

几个细节值得注意：

- **币种**：DMIT 结算单位是美元，支付宝会按当日汇率自动换算成人民币，最终扣款是人民币。
- **汇率**：支付宝的汇率通常比银行柜台略高一点，但差距不大，正常范围内。
- **发票/收据**：付款完成后 DMIT 后台会生成一张美元计价的收据，支付宝那边也有人民币的交易记录，两边都有凭证。
- **充值余额**：DMIT 支持先往账户余额里充钱，之后用余额续费，这样不用每次续费都重新走支付宝流程，方便一些。

## 线路怎么选：CN2 GIA 和 CMIN2 的区别

这是买 DMIT 最容易纠结的地方，简单说一下我的理解。

**CN2 GIA** 是电信的精品网络，走的是 59.43.x.x 这段 IP 段，全程 QoS 保障，绕过公网拥堵节点。电信宽带用户用这条线路，延迟和稳定性都很好。联通用户也能用，效果次之。

**CMIN2** 是移动的精品网络，全称 China Mobile Next Generation Network。如果你家宽带是中国移动，CMIN2 的体验会比 CN2 GIA 更好——延迟更低，晚高峰也不容易抖。

判断方法很简单：看你家宽带运营商。

- 电信宽带 → 优先考虑 CN2 GIA 系列
- 移动宽带 → 优先考虑 CMIN2 Premium 系列
- 联通宽带 → CN2 GIA 也可以，或者看 DMIT 是否有联通优化线路

在我实际使用中，洛杉矶 CN2 GIA 的晚高峰延迟稳定在 160ms 左右，丢包率基本可以忽略，这个表现在同价位里算扎实的。
